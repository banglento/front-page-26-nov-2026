# news-image-20261126 — The World Today

A 1024x1024 newspaper front page summing up the world's news of
Thursday 26 November 2026, drawn entirely in code.

## Run

```sh
python3 main.py
```

Writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `out/`).
Standard library only, no network, fully deterministic — two runs
produce byte-identical PNGs.
